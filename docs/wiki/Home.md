## 🚀 Inicio Rápido

```bash
# 1. Clonar repositorio
git clone https://github.com/AlejoCeron-col/Visitalaslajas.git
cd Visitalaslajas

# 2. Instalar dependencias
npm install

# 3. Configurar variables de entorno
cp .env.example .env

# 4. Iniciar servidor
npm run dev

# 5. Abrir en navegador
# http://localhost:3000
```
